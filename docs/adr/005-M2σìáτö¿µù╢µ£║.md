# ADR-005 M2 何时占用教室

- 状态：提议（项目启动会讨论后改为"已采纳"）
- 日期：2026-10-12
- 决策人：C
- 相关需求：REQ-M2-04、REQ-M2-06、INT-02

## 背景

任务书："整教室预约审批通过后，该室在预约时段内的全部座位被占用……审批驳回或超时撤销后回滚。"对"回滚"有两种理解：占用发生在提交时（驳回后回滚），或发生在通过时（通过后撤销才回滚）。

## 备选方案

| 方案 | 优点 | 缺点 |
|---|---|---|
| A. 提交申请时预占，驳回或超时释放 | 与"驳回后回滚"字面一致；审批期间不会有新的个人预约 | 审批期间（最长数天）座位不可约，降低利用率；被驳回的申请也会取消学生预约 |
| B. 最终审批通过时占用；通过后撤销或取消时释放 | 只有确定使用时才影响学生 | 与字面略有出入，需要说明；审批期间仍可能产生新的个人预约（通过时一并取消并通知） |

## 决定

采用 B。任务书第一句明确"审批通过后……被占用"，回滚理解为"通过后被撤销（申请人取消）时回滚"；pending 阶段的驳回、超时不存在占用，因此无需回滚。审批人在待办中可以看到批准后将被取消的个人预约数（REQ-M2-08）。

## 后果

- 被驳回的申请不会影响任何学生，符合座位利用率目标。
- 第一次 Review 时向老师说明这一理解；如老师要求按 A 实现，改动集中在 M2 提交与驳回流程，M1 接口不变。
